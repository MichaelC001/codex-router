# ChatGPT ネイティブアカウントの切り替え

[English](../CHATGPT-ACCOUNT-MODES.md) · [简体中文](../zh-CN/CHATGPT-ACCOUNT-MODES.md) · 日本語

Control Center で保存済み ChatGPT アカウントを選び、Codex を終了して再起動すると適用します。ログインはアカウントごとに分離した profile に保存します。

## カタログと既定モデル

各アカウントは独自のネイティブカタログと Router オーバーレイを保持します。次回の Codex 起動で選択を使い、外部モデルはプロバイダールートの設定に従います。

## 使用量

最大八つの保存済みかつ利用可能なアカウントの分離された `CODEX_HOME` から読み込みます。現在のアカウントを優先し、利用できる週次または月次ウィンドウを表示します。アカウントは利用者が明示的に切り替えます。

## トークン更新と削除

公式 Codex の認証処理がトークンを更新します。再ログインが必要な場合は公式の `codex login` を使います。アカウント操作ではほかのセッションを保持し、profile の削除時は対象アカウントと保持するデータを確認します。
