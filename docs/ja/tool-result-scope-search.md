# 同一スコープ内の原文検索

[English](../tool-result-scope-search.md) · [简体中文](../zh-CN/tool-result-scope-search.md) · 日本語

原文の読取コマンドは有効な参照ハンドルと `--scope-search --find 'literal identifier'` を受け取り、同じ署名付き対話/権限スコープのアーカイブから正確な抜粋を返します。

完全性、署名、期限、通常ファイルとディレクトリの所有条件を検証します。出力には抜粋長、件数、走査予算の上限があります。現在は一致アーカイブ 32 件、走査 16 MiB、ファイル間で確認する一秒の予算です。

`complete: false` は不完全な結果を示します。`nextCursor` がある場合は `--cursor N --index HASH` で続け、索引が変わった場合は最初から検索します。ページを進める間も既存の一致結果と利用できない項目の報告を保持します。

各アーカイブの最初の一致を返します。追加文脈や後続の一致は単一アーカイブの `--offset` で読みます。抜粋長は UTF-16 で数え、サロゲートペアの保持で一コード単位多くなる場合があります。
