# デスクトップアーカイブの読取証明

[English](../tool-result-readback-proof.md) · [简体中文](../zh-CN/tool-result-readback-proof.md) · 日本語

ローカル原文の読取コマンドは署名付き証明を返します。Router は実行環境が同じ対話/権限スコープの原文にアクセスできることを確認し、検証後に履歴出力を省略します。

デスクトップツールの JSON が別の結果構造に包まれる場合もあります。デコードは八階層、完全な JSON 文字列 64 KiB、配列先頭 64 要素、既知の `text`、`output`、`content`、`value` などに限定します。

署名、有効期限、スコープを検証します。証明がない、偽造、期限切れ、別スコープ、アクセス不可の場合は全文を保持します。読取コマンドは保存済みテキストを読み、元のコマンドの再実行は新しい状態観測になります。

操作と削除は [Codex ガイド](CODEX.md)、原文をまたぐ検索は[スコープ検索](tool-result-scope-search.md)を参照してください。
