- **Old tool results are omitted only after an exact snapshot is available for local readback.** A signed readback proof is required in the same conversation and permission context before omission; sandboxed clients that cannot read the private store keep full output. Receipts retrieve paginated original text instead of asking the model to rerun a potentially mutating tool. Missing local execution tools, failed storage, capacity limits and corrupt snapshots preserve the full result; expired or purged snapshots report unavailable evidence explicitly.
