- **Atlas Cloud is now a catalog-only provider.** Its OpenAI-compatible gateway (`https://api.atlascloud.ai/v1`, key `ATLASCLOUD_API_KEY`, endpoint override `ATLASCLOUD_API_BASE_URL`) is registered for routing and credential isolation like Together AI and SiliconFlow. It ships no preselected models: store a key, then run `./bin/curate-models atlascloud` to choose models from its live catalog.
