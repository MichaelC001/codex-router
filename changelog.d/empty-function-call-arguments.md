- **Routed models can no longer hand Codex a tool call with empty arguments for a tool that takes inputs.** An empty argument string is still relayed for a declared tool whose schema takes no inputs. For any other tool, a completed call with empty arguments is refused before Codex stores it, the same as truncated JSON. Threads already broken this way recover by themselves: the router leaves out an empty-argument call whose only output is Codex's `EOF while parsing` failure, because that call never ran. A stored empty call to a known input-taking tool that has any other output is refused with a clear 400 (#1066).
