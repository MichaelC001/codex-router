- **The service supervisor no longer hangs after the router crashes.** `start.mjs` waited without a limit for every child to report its exit, so on Windows a lost exit event (seen after a native `0xC0000409` abort) left it running with no children and no ports, and the Scheduled Task never restarted the router. The final wait now gives up a few seconds after the SIGKILL backstop and exits nonzero, so the service manager restarts it (#1020).
